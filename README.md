# nuharian.github.io

Personal academic website of **Arian Nuhan**, AI safety and security researcher
(BSc in Computer Science and Engineering, BRAC University).

Live at **https://nuharian.github.io/**

A single static page (`index.html`), served by GitHub Pages. No build step.
To update it, edit `index.html`, bump the "Last updated" date and the `lastmod` in `sitemap.xml`, then push.
